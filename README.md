# Martina Solés portfolio

## 1. Get the images (once)
Open Terminal, go into this folder and run:

    bash download-images.sh

It downloads all your Framer images into `images/`. Open `index.html` in your browser to check.

## 2. Things to fill in
- `index.html`: replace `https://www.linkedin.com/in/YOUR-HANDLE` with your LinkedIn
- Add your CV as `cv.pdf` in this folder

## 3. Put it online (GitHub Pages)
1. Create a repo on GitHub, e.g. `portfolio`
2. Upload everything in this folder (Add file > Upload files)
3. Settings > Pages > Deploy from branch > `main` / root
4. Later: add your own domain in the same Pages settings

To edit text, the case studies are in `work/`. Styles are all in `css/style.css`.
